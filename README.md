# Nova

**Nova** 是一个桌面游戏平台客户端的界面原型，整体产品思路与使用体验参考 Steam，但拥有自己独立的视觉语言与品牌设计，不包含任何 Steam 的界面或品牌元素。

项目为纯前端实现，所有数据均为 Mock Data，无真实后端。

## 功能模块

- **商店**：游戏封面展示、分类浏览、搜索、筛选与排序
- **游戏库**：已购游戏浏览、安装状态管理
- **下载管理**：下载队列、进度与状态控制
- **好友**：在线状态、好友列表与互动
- **游戏详情**：游戏介绍、截图、成就与相关信息
- **成就**：成就列表与解锁进度
- **个人资料**：用户信息、游戏数据展示

交互上包含搜索、筛选、排序、Hover 效果、弹窗、下载状态、在线状态、加载与空状态等完整细节。

## 技术栈

- React 19 + TypeScript
- Vite
- Tailwind CSS 4
- React Router
- Zustand（状态管理）
- Motion（动效）
- Lucide React（图标）

## 快速开始

```bash

```

```bash

```
